# Zeelin 公众号风格（可选）

仅在用户选择本风格时启用；这些是编辑偏好，不是所有中文写作的通用语法禁令。

- 科技公众号正文默认约2000字，这是阅读负担目标，不是最低字数。当次要求优先。
- 尽早交代具体主体与动作，不用万能时代背景开篇。
- 按事实关系推进，不为了整齐强拆三个层面、四本账或对称排比。
- 先写具体名词和普通动作。删除装饰性拟人、空泛比喻、没有信息作用的副词。
- 保持核心概念用词一致，不靠反复换同义词制造文采。
- 少用连续冒号，依中文语义拆成完整句；网址、时间、比例、代码和引语中的冒号不机械改动。
- 不把核验过程、作者如何定性材料、配图建议和QA标记留在正文。
- 同一事实边界交代清楚一次，后文推进新信息；不反复提醒已知的限制。
- 结尾停在本篇独有的事实、直接影响或真正未解的问题，不重新盘点全文。
- 同一堵墙、同一笔账、数字是真的因果没那么简单等表达在作者叙述中优先重写。根据事实说明限制、成本、统计对象和因果，不换另一套比喻。

真实语音功能、网络层级、必要术语和有来源引语优先保证准确，不因风格偏好擅改。用户没有要求该风格时使用general。

检查命令：

~~~sh
python scripts/check_pre_ai_style.py article.txt --profile zeelin --json
~~~
